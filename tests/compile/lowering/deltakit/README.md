# Deltakit backend validation

Reference TQEC commit: `5439358c4ad76f7b09254f46f9ea4ea27d033fc7`.
Deltakit-compile source: `e242562f1387b7efdff23d2bc7ea351f8b6edd03`, version 0.1.0.
The initial environment uses Python 3.11.16, xDSL 0.68.0 and deltakit-stim 0.2.7.
Install the source commit explicitly; the package was not available from the
package index used for validation. The existing 42 Stim construction snapshots
are an independent reference and must not be regenerated by this backend.

The API smoke test builds native circuits, validates measurement SSA and exports
both physical xDSL IR and Deltakit-Stim. It does not establish full TQEC physical
or QEC equivalence. The production adapter must never import a Stim circuit as
its input. Deltakit's own deltakit-stim dependency is a separate dependency.
